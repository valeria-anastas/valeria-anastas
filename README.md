### Подробнее об учебных работах

#### 📊 [A/B-анализ лендинга — исследование конверсии](projects/ab-landing-page/README.md)
- Подготовила и очистила данные, проверила корректность экспериментальных групп.
- Для лендинга рассчитала конверсию, провела **z-тест двух долей** и **bootstrap** с доверительными интервалами.

**Стек:** Python · pandas · NumPy · SciPy · Matplotlib · Seaborn

#### 🏠 [Статистический анализ рынка аренды недвижимости](projects/rental-market-statistics/README.md)
- Подготовила данные по **9 531 объявлению**: обработала пропуски, отфильтровала некорректные значения и выбросы.
- Проверила различия стоимости аренды за квадратный фут между квартирами с разным числом спален с помощью **Welch ANOVA** и **Games–Howell**.
- Исследовала связь между количеством спален и заявленных удобств с помощью **χ²-критерия независимости**.
- Сравнила среднюю стоимость аренды в зависимости от наличия информации о разрешении питомцев с помощью **t-теста Уэлча** и **bootstrap**; статистически значимого различия при α = 0,05 не обнаружила.
- Описала ограничения наблюдательных данных и сформулировала выводы по результатам проверки гипотез.

**Стек:** Python · pandas · SciPy · Matplotlib · Seaborn

#### 🎬 [Netflix EDA — исследование каталога и пользовательских оценок](projects/netflix-eda/README.md)
- В рамках командного учебного проекта исследовала структуру данных Netflix: **1 000 исходных записей, 500 точных дублей**.
- В опубликованной версии: обработка пропусков, анализ возрастных категорий, числовых оценок, годов выпуска, жанров и географии по расширенному каталогу **7 787 записей**.
- Сопоставлены оценки шоу 2016 и 2017 годов; отмечены ограничения статистических выводов и неполнота данных.
- Изучены агрегированные LLM-метки предполагаемой аудитории; **это гипотезы модели, а не фактическая структура зрителей Netflix**. Полные LLM-ответы не публикуются, агрегаты включены в проект.

**Стек:** Python · pandas · NumPy · Matplotlib · Seaborn · SciPy
