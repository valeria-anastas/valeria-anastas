## Проекты

### [A/B-тест лендинга](https://github.com/valeria-anastas/ab-landing-page)

Проверила, помогает ли новая версия страницы повысить конверсию. Очистила данные, проверила группы эксперимента и оценила результат с помощью статистических тестов и бутстрэпа.

**Итог:** значимого улучшения не обнаружила. Для меня главный вывод — не стоит объявлять изменение успешным, если данные этого не подтверждают.

[Код и результаты](https://github.com/valeria-anastas/ab-landing-page/blob/main/ab_landing_page_analysis.ipynb)

### [Статистический анализ рынка аренды](https://github.com/valeria-anastas/rental-market-statistics)

Исследовала объявления о недвижимости: как связаны цена, площадь, количество спален и удобства. Проверила гипотезы о стоимости аренды и характеристиках квартир, отдельно разобрала ограничения данных.

[Код и результаты](https://github.com/valeria-anastas/rental-market-statistics/blob/main/rental_market_analysis.ipynb)

### [Netflix: исследование каталога](https://github.com/valeria-anastas/netflix-eda)

Командный проект, в котором мы изучали каталог Netflix: очищали данные, сравнивали оценки, жанры, страны и годы выпуска. Отдельная часть исследования — классификация предполагаемой аудитории с помощью LLM. Это гипотезы модели, а не информация о реальных зрителях.

[Notebook с графиками](https://github.com/valeria-anastas/netflix-eda/blob/main/netflix_eda.ipynb)

### [Как заинтересовать молодёжь инвестициями в недвижимость](https://github.com/valeria-anastas/cup-russia-zpif)
