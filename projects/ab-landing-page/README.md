# A/B-тестирование лендинга: оценка влияния новой страницы на конверсию

**Учебный аналитический проект** · Python · pandas · SciPy · статистика · bootstrap

## Бизнес-вопрос

Есть две версии страницы: `old_page` (контроль) и `new_page` (тест). Нужно выяснить, дает ли новая версия статистически обоснованное изменение конверсии (`converted`) и стоит ли внедрять её ради роста целевой метрики. Точный первоначальный бизнес-бриф неизвестен; постановка адаптирована из учебного задания.

## Этапы

1. Проверка датасета, пропусков и экспериментальных групп.
2. Удаление несогласованных назначений страницы и повторных пользователей (сохранение первого согласованного наблюдения).
3. Проверка SRM при **допущении** сплита 50/50.
4. Расчёт конверсии, визуализация динамики.
5. Двусторонний z-тест двух долей, доверительный интервал и bootstrap.
6. Интерпретация для продуктового решения.

## Результат анализа исходного CSV

| Метрика | Значение |
| --- | ---: |
| Строк до очистки | 294 478 |
| Пользователей после очистки | 290 584 |
| Контроль | 12,039% (17 489 / 145 274) |
| Тест | 11,881% (17 264 / 145 310) |
| Разница тест − контроль | −0,158 п.п. |
| Двустороннее p-value | 0,190 |
| 95% ДИ разницы | [−0,394; +0,078] п.п. |

**Вывод:** статистически значимого роста конверсии не обнаружено. На этих данных внедрение нового лендинга ради повышения конверсии не обосновано. Это не доказывает, что обе страницы эквивалентны.

## Файлы и запуск

- [**ab_landing_page_analysis.ipynb**](ab_landing_page_analysis.ipynb) — исследование с постановкой задачи, кодом, графиками и объяснениями.
- [**requirements.txt**](requirements.txt) — необходимые библиотеки.

Для запуска: `pip install -r requirements.txt`, затем положить `data_ab.csv` рядом с Notebook и выполнить все ячейки.

**Датасет намеренно не выложен:** разрешение на публичное распространение не подтверждено, а в CSV есть идентификаторы пользователей. В Notebook нет персональных выгрузок, но сохранённые результаты статистических расчётов можно проверить при наличии оригинального набора данных. Код и логика анализа доступны для изучения без CSV.

## Ограничения

- Подтверждённый экспериментальный дизайн и экономическая оценка отсутствуют.
- Равномерное распределение 50/50 принято как допущение для SRM.
- Очистка повторов и несовпадений может влиять на полученную оценку.
- Это **учебный кейс**, а не коммерческий проект.
