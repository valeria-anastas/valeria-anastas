# A/B-тестирование лендинга: оценка влияния на конверсию

**Учебный аналитический кейс** · Python · pandas · SciPy · Matplotlib · Seaborn · статистические гипотезы · bootstrap

## Постановка задачи

В наборе данных представлены наблюдения по двум версиям лендинга: контрольной (`old_page`) и тестовой (`new_page`). Необходимо выяснить, приводит ли новая версия к изменению конверсии (`converted`) и можно ли рекомендовать её внедрение.

Исходное университетское задание переработано в самостоятельный проект для портфолио. Точный коммерческий бриф и экономические параметры эксперимента неизвестны; они не выдумываются.

## Какие шаги выполнены

1. Загрузка исходного CSV и проверка качества данных.
2. Анализ соответствия экспериментальной группы показанной странице, исключение несогласованных строк.
3. Удаление повторных наблюдений пользователей и проверка SRM (при предполагаемом распределении 50/50).
4. Исследование динамики эксперимента и конверсии.
5. Двусторонний z-тест для двух долей и 95% доверительный интервал.
6. Bootstrap-оценка эффекта и оценка необходимого объёма выборки.
7. Интерпретация результата с точки зрения продуктового решения.

## Ключевые результаты

| Показатель | Значение |
| --- | ---: |
| Исходные наблюдения | 294 478 |
| Пользователей после очистки | 290 584 |
| Контрольная группа | 17 489 / 145 274 · **12,039%** |
| Тестовая группа | 17 264 / 145 310 · **11,881%** |
| Изменение конверсии (тест − контроль) | **−0,158 п.п.** |
| Двустороннее p-value | **≈ 0,190** |
| 95% доверительный интервал разницы | **[−0,394; +0,078] п.п.** |

**Вывод:** статистически значимого улучшения конверсии на уровне значимости 5% не выявлено. На основании этого эксперимента нельзя рекомендовать новый лендинг *именно ради роста конверсии*. Отсутствие статистической значимости не означает доказанного равенства вариантов.

## Как запустить

1. Скачайте папку проекта либо клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Откройте `ab_landing_page_analysis.ipynb` в Jupyter Notebook или VS Code.
4. Выполните все ячейки по порядку. Файл `data_ab.csv` уже лежит рядом с Notebook.

## Ограничения

- Проект учебный, а не коммерческий.
- Точный дизайн рандомизации и бизнес-стоимость внедрения не представлены.
- Для проверки SRM предполагается целевой сплит 50/50; его следует подтвердить по экспериментальному дизайну.
- Исключение повторных и несогласованных наблюдений — аналитическое допущение, способное влиять на оценку эффекта.
