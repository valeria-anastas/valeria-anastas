# Проверка воспроизводимости Netflix EDA

Проверена локальная **расширенная версия** исследования на исходных данных. Jupyter Notebook выполнился без ошибок: **9 из 9 кодовых ячеек** с сохранёнными таблицами и графиками. Расширенная локальная версия использует `catalog_1.csv`, `catalog_2.csv` и очищенную таблицу отдельных LLM-меток, тогда как GitHub-версия публикует **восемь частей каталога и только агрегаты LLM**. Это разные сборки, и факт локального выполнения сам по себе не подтверждает выполнение GitHub-версии.

## Проверенные факты

| Набор | Количество |
| --- | ---: |
| Исходные записи NetflixShows | 1 000 |
| Точные дубли NetflixShows | 500 |
| Уникальные записи NetflixShows | 500 |

| Расширенный каталог | 7 787 |

| Записи LLM-классификации | 8 807 |

| Записи LLM с флагом ошибки | 438 |
| Идентификаторы LLM вне расширенного каталога | 1 020 |

**Ограничение:** классификация аудитории — результат модели, не измеренная информация о реальных зрителях. Представленность контента в наборе не доказывает популярности или числа просмотров.

**Дополнительно подтверждено на GitHub:** workflow `execute-netflix.yml` выполнил опубликованный Notebook: **12 из 12 кодовых ячеек**, ошибок нет, результаты сохранены в файле (в том числе **7 графиков PNG**). Таким образом, воспроизводимость опубликованной версии проверена отдельно от локальной расширенной версии.
