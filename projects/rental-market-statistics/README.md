# Статистический анализ аренды недвижимости

**Учебный проект, часть 2** · Python · pandas · SciPy · статистические гипотезы

Исследование объявлений об аренде, **не A/B-эксперимент**. Проверены связи между характеристиками квартир и стоимостью аренды.

## Файлы

- [Notebook с кодом](rental_market_analysis.ipynb)
- [Обезличенный датасет](rental_clean_data.csv) — **9 531 запись**, семь аналитических полей, без адресов, идентификаторов и описаний
- [Зависимости](requirements.txt)

## Проверяемые гипотезы и результаты

| Вопрос | Метод | Результат |
| --- | --- | --- |
| Различается ли цена за квадратный фут по числу спален (1, 2, 3+)? | Welch ANOVA, Games–Howell | p ≈ 6,14 × 10⁻¹⁸⁰ |
| Есть ли связь числа удобств и числа спален? | χ² независимости по известным значениям удобств | χ² ≈ 58,23; p ≈ 2,27 × 10⁻¹³ |
| Различается ли цена при явном указании разрешённых питомцев и отсутствии сведений о них? | Welch t-test, bootstrap | Разница ≈ −19,42 USD; p ≈ 0,0618 |

**Важное ограничение:** в датасете нет подтверждённой категории «питомцы запрещены». Пропуск означает отсутствие сведений, а не запрет. В исходном учебном Notebook также тест Tukey HSD ошибочно назывался Games–Howell; в опубликованной версии применяется соответствующий метод. Пустые сведения об удобствах теперь не считаются нулём, поэтому оценка χ² пересчитана.

## Запуск

```bash
git clone https://github.com/valeria-anastas/valeria-anastas.git
cd valeria-anastas/projects/rental-market-statistics
pip install -r requirements.txt
jupyter notebook rental_market_analysis.ipynb
```

Notebook уже выполнен, а таблицы и графики сохранены для просмотра прямо на GitHub. Для повторного запуска выполните все ячейки по порядку; CSV приложен. Площадь измеряется в **квадратных футах**, не квадратных метрах.

Выводы относятся к наблюдательным данным и не доказывают причинно-следственные связи. На результат могут влиять город, площадь, класс жилья и правила очистки данных.
