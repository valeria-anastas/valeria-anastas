# Рынок аренды недвижимости: статистический анализ

**Учебный проект · Python / pandas / SciPy / Pingouin · исследование наблюдательных данных**

## Постановка задачи
Изучить объявления о сдаче квартир в США (исходный датасет за 2019 год) и проверить три гипотезы:

1. Отличается ли средняя аренда за квадратный фут между объектами с 1, 2 и 3+ спальнями?
2. Связана ли категория количества удобств с количеством спален?
3. Различается ли средняя месячная аренда в зависимости от условий проживания с питомцами?

**Это не A/B-эксперимент:** работа составляет вторую часть присланного общего учебного Notebook; первая посвящена A/B-тесту лендинга. Анализ недвижимости выделен в отдельный проект.

## Аналитический подход
- Загрузка и проверка 9 531 записи, 22 исходных полей;
- обработка пропусков, выбор месячной аренды и верхних выбросов по категориям;
- описательная статистика и визуализации;
- **Welch ANOVA + Games–Howell** для сравнения трёх групп;
- **χ²-критерий независимости** для двух категориальных переменных;
- **t-тест Уэлча + bootstrap** для сравнения цены двух групп.

## Итоги исходной учебной версии
| Гипотеза | Итог |
| --- | --- |
| Цена за кв. фут и число спален | Значимые различия, Welch ANOVA p ≈ 6,14 × 10⁻¹⁸⁰ |
| Удобства и число спален | Значимая связь, χ² ≈ 106,38, p < 0,001 |
| Цена и проживание с питомцами | Значимых различий на 5% не обнаружено, Welch p ≈ 0,0618 |

Результаты в таблице отражают **исходную учебную работу**. В опубликованном Notebook уточнена обработка неизвестных категорий питомцев и исправлено попарное сравнение на Games–Howell вместо ошибочно подписанного Tukey HSD: новые оценки могут отличаться, поэтому их нужно получать запуском кода.

Это анализ наблюдательных объявлений, не причинный эксперимент. Местоположение, характеристики помещений, правила кодирования категорий и исключение выбросов могут менять результат. `square_feet` — квадратные футы, не квадратные метры.
